# РИКОШЕТ — состояние сборки

Telegram Mini App. Дуэль 1-на-1 на скилл: одна арена в день для всех,
5 выстрелов, один толчок в полёте, счёт сравнивается с «призраком» друга.
Монетизация — только Stars за косметику + пропуск на 30 дней. Без ставок.

Обновлено 22.10.2026, после живой проверки в браузере.

## Как запустить у себя

```sh
python3 -m http.server 8099 --bind 127.0.0.1    # из корня репозитория
# открыть http://127.0.0.1:8099/client/
node tools/verify.mjs                            # приёмка, 94 проверки
ALLOW_MISSING_WRANGLER=1 WORKER_ORIGIN=https://<воркер>.workers.dev bash scripts/deploy.sh
```

## Открытый вопрос к владельцу

Проверить на fragment.com, доступен ли вывод Stars → TON для Таджикистана.
ToS Telegram предупреждает, что Fragment «may be unable to issue rewards in
certain countries». Если вывода нет — Stars не монетизация, и надо менять
способ оплаты. Это решает, имеет ли смысл достраивать магазин.

Цифры для трезвости: 1000 ⭐ ≈ 1.30 $ при выводе, минимум к выводу 1000 ⭐,
удержание до 21 дня. Скин за 50 ⭐ ≈ 6.5 цента, то есть 100 $ — это примерно
1500 покупок.
