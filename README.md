# РИКОШЕТ / RICOCHET

Telegram Mini App: дуэль на одну точность. Одна арена в день одинакова для
всех, 5 выстрелов и один толчок мяча в полёте; счёт сравнивается с «призраком»
друга. Бесплатно. За Telegram Stars продаётся только косметика и пропуск на
30 дней — ни ставок, ни лутбоксов, ни платных случайных награ́д.

## Архитектура

```
              Telegram
      initData │ openInvoice │ CloudStorage
               ▼
  GitHub Pages ─────────► client/        canvas, прицел, экраны, звук
   (статика, HTTPS)         │  fetch /api/* + Bearer-токен
                            ▼
                  Cloudflare Worker ──────► D1
                   проверка initData,       users, runs,
                   пересчёт счёта,          duels, purchases
                   лидеры, дуэли, Stars
                            │
                            └── вебхук бота: /start (диплинк дуэли),
                                pre_checkout_query, successful_payment,
                                /paysupport, /delete, возвраты
```

`shared/sim.js` — единственная физика. Клиент считает её для картинки, воркер
переигрывает те же выстрелы, и счёт воркера считается единственно верным;
поэтому подмена клиента ничего не даёт.

Клиент спроектирован жить без сервера: арена дня выводится из даты локально,
лучший счёт лежит в CloudStorage, неотправленные забеги ждут в офлайн-очереди
в `localStorage`. Без `/api` недоступны только лидеры, дуэли и магазин.

## Физика заморожена

`tests/golden.json` хранит хеши 150 прогонов. Любое изменение `shared/sim.js`
— даже порядок сложений — ломает `tests/golden.test.mjs`. Менять физику только
осознанно: сначала зачем, потом пересчёт golden-файла, и помнить, что старые
результаты в таблице лидеров станут несопоставимы с новыми.

## Запуск локально

```bash
cd /Users/osim/Projects/ricochet
python3 -m http.server 8099 --bind 127.0.0.1
# открыть http://127.0.0.1:8099/client/
```

Сервер поднимается **из корня репозитория**, а не из `client/`: клиент
импортирует `../../shared/sim.js`, значит `shared/` должен лежать уровнем выше
`client/`. Поэтому `/client/` в URL — не опечатка; через `file://` ES-модули
не работают. На localhost `config.js` сам выбирает `/api`. Вне Telegram SDK
нет, и `client/js/tg.js` это переживает: игра идёт, покупок и шаринга нет.

## Тесты

```bash
node tests/sim.test.mjs      # физика и правила счёта: 4297 проверок
node tests/golden.test.mjs   # 150 прогонов повторяются побайтово
node tools/balance.mjs       # баланс: сильный против слабого
```

Оба теста выходят с кодом 1 при провале. `scripts/deploy.sh` прогоняет их и
отказывается собирать сборку, если хоть один упал.

## Сборка и публикация

```bash
WORKER_ORIGIN=https://<worker>.<subdomain>.workers.dev bash scripts/deploy.sh
```

Проверяет `node` и `wrangler`, прогоняет оба теста, собирает `dist/`
(`client/` и `shared/` рядом, чтобы `../../shared/...` разрешался, плюс
`pages/*` в корень сайта) и печатает готовые команды для `wrangler deploy` и
для публикации `dist/` в ветку `gh-pages`. Сам ничего не деплоит и не пушит.

`WORKER_ORIGIN` подставляет адрес воркера в `dist/client/js/config.js` (только
в копию, исходник остаётся с заглушкой — на localhost нужен `/api`). Без него
сборка выйдет офлайн-режимной: без лидеров, дуэлей и магазина, о чём скрипт
громко предупредит. Другие ручки: `DIST_DIR=/tmp/ric` — собрать в другое
место, `ALLOW_MISSING_WRANGLER=1` — собрать без установленного wrangler.
`dist/` в git держать не нужно (строка `dist/` в `.gitignore`).

Настройка бота и подача в модерацию — `scripts/botfather.md`. Секреты (токен
бота, секрет вебхука, ключ подписи токенов) живут только в
`wrangler secret put ...`; в репозитории их нет и быть не должно.

## Клиент и воркер на разных доменах

Статика живёт на GitHub Pages, воркер — на `workers.dev`, поэтому запросы
кросс-доменные. Нужны обе половины: `WORKER_ORIGIN` при сборке (адрес воркера
в клиенте) и `ORIGIN` в `worker/wrangler.toml` — CORS-алловлист, в котором
должен быть `https://<user>.github.io`, иначе браузер заблокирует все вызовы.
Пока адрес не подставлен, `API_CONFIGURED` в `config.js` равен `false`, и
клиент не стучится никуда: арена дня и тренировка работают, остальное — нет.
